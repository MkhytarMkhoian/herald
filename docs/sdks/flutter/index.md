# Flutter SDK

!!! info "In development"
    Herald for Flutter is being written. It will bring the same events, interfaces and factories
    to Dart, with modules for the same vendors, published on pub.dev.

    Everything under [Philosophy](../../philosophy.md), [Concepts](../../concepts/events-and-properties.md)
    and [Guides](../../guides/routing.md) describes Herald itself, not one platform, so it applies
    to the Flutter SDK too. Code examples will get a **Dart** tab when the SDK is released.

To follow progress, watch the [Herald repository](https://github.com/MkhytarMkhoian/herald).
