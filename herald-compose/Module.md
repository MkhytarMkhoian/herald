# Module herald-compose

Tracking from composables that have no ViewModel to track through: `LocalEventTrackerService`,
`TrackScreenView`, `TrackOnLifecycleEvent`, `rememberTracker` and `Modifier.trackImpression`.
Requires no DI framework.

See [Compose](https://mkhytarmkhoian.github.io/herald-docs/sdks/android/compose/).
